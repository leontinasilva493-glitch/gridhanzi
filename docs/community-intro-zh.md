# 把词表变成能打印的汉字练习纸：我做了 GridHanzi

老师备课时，词表已经有了，还得核对拼音、排练字格。家长想照着孩子这周学的字打印一页，现成字帖又不一定对得上。自己学中文也类似：记下几个新字，想动笔写写，却还要先找合适的练习纸。

我做了 GridHanzi，想省掉这段整理工夫。把英文或中文词表贴进去，逐条核对、修改汉字、拼音和释义，再选描红、田字格、米字格或空白书写格，下载 A4 或 US Letter PDF。老师可以按课堂词表出练习纸，家长能打印孩子要复习的字；自己练习时，也可以先查笔顺，再动笔写。

没有现成词表的话，可以从主题或 HSK 模板开始。工具免费，生成字帖无需注册。
