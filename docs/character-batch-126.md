# Classroom and beginner communication batch: 102 to 126

## Selection rationale

These 24 characters fill gaps in introductions, classroom roles, questions, ability/wants, and reading/writing. Selection is based on overseas teaching relevance, not measured search volume. No monthly volume, keyword-difficulty score, popularity ranking, or institutional endorsement is claimed. Existing 102 guides are preserved.

## Editorial safeguards

- Four original example phrases/words and three original sentences per page; source vocabulary lists are evidence, not copied textbook explanations.
- Independent reading, usage, visual-form, writing-tip and confusable-form explanations. Optional duplicate useNotes/commonMistake sections are omitted.
- Three relevant published character links per page. All guides are server-linked from the stroke-order hub and included in the English sitemap.
- Neutral-tone defaults: 吗 ma, 呢 ne, 么 me. Explicit alternatives include 都 dōu/dū, 会 huì/kuài, 要 yào/yāo, 看 kàn/kān and 呢 ne/ní.
- Title/H1 follow the existing character + Pinyin + stroke-order format. Descriptions highlight actual differences such as grammar contrasts and shapes.
- No independent teacher sign-off is claimed; checks are editorial, source cross-checks, structural tests and runtime verification.
- Existing Chinese noindex and business-parameter index boundaries are retained.
