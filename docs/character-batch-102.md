# Foundation character batch: 54 to 102

## Scope and selection

48 new guides selected by basic teaching coverage: numbers, body parts, family, natural objects, colours, animals, and daily words. This is not a search-volume ranking. No fresh GSC or Keyword Planner export was used. Existing title formats and the worksheet CTA are preserved.

Each guide has four example words, three sentences, an explicit reading, simplified/traditional forms, visual structure, writing advice, a confusable form, HSK evidence, and related published guides. Explanations describe the modern visual form, not a claimed historical etymology. Sentence difficulty labels are editorial, not HSK assignments.

## Verification sources

- Stroke paths and counts: https://cdn.jsdelivr.net/npm/hanzi-writer-data@2.0.1/ (48 individual JSON files successfully downloaded; path and median counts agree).
- Reading/radical cross-check: https://github.com/skishore/makemeahanzi/blob/master/dictionary.txt ; this is a cross-check, not an authoritative single-reading policy. 子 explicitly teaches zǐ and the neutral suffix zi. 电 uses the conventional simplified dictionary radical 田 rather than the source classification 曰.
- HSK evidence: repository hsk-catalog.json. A compound containing a character is labelled word-family evidence; it does not assign that character a standalone HSK level.
- Educational review: AI editorial and consistency checks; no independent teacher sign-off is claimed.
