## 任务顺序

1. 教师：用自己的 10–15 个非敏感课程词制作一份练习纸，修改一个拼音或释义，然后预览并导出。
2. 家长：打开 Numbers 或 First Characters，说明想用的纸张，下载成品；再修改两个词重新导出。
3. 主持人先不指导；记录第一次犹豫、出错和求助的位置。不得要求上传学生姓名、照片或私密课堂材料。
4. 打开 PDF，核对内容、纸张与页数。只有实际打印并确认后，才记录为打印完成。
5. 修正最大的卡点后，邀请同一位参与者再做一次；询问是否愿意下次继续使用。

## 统计口径

- worksheet_editor_open：打开编辑器，不等于开始编辑。
- worksheet_preview_open：从编辑器发起预览，不等于渲染完成。
- worksheet_download_start/success/failure：浏览器生成流程，不证明文件已落盘或实际打印。
- worksheet_pack_download_click：点击现成文件链接，不等于保存完成。
- 以会话去重后比较导出开始与成功；不要直接把事件次数相除当用户转化率。
- 按落地页、来源、纸张比较；来源缺失记为未知，不补猜 AI 来源。
- paper_size 是事件参数；GA4 报表如需自定义维度，应在确认目标属性后配置。
- 不上报词表、标题、学生姓名、邮箱或反馈正文。
